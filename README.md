# Obstacle Avoider Rover

A robotics project featuring a custom-designed chassis, PCB, and obstacle avoidance system.

## Features

- Three ultrasonic sensors for obstacle detection
- Arduino Nano-based control system
- L293D dual motor driver
- Two DC geared motors
- Custom PCB designed using EasyEDA
- 3D chassis designed using Autodesk Fusion 360

## Project Structure

- CAD/: Chassis and component models
- PCB/: PCB design and manufacturing files
- Firmware/: Arduino firmware
- Documentation/: Project images and notes

## Hardware

- Arduino Nano V3
- L293D motor driver
- HC-SR04 ultrasonic sensors
- Two TT geared DC motors
- Battery and power connectors

## Software

- Arduino IDE
- EasyEDA
- Autodesk Fusion 360
